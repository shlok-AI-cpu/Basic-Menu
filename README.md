
# ☕ Basic Menu - Python Cafe Ordering System

A beginner-friendly Python project that simulates a simple cafe ordering system. Customers can browse the menu, place multiple orders, select quantities, and calculate their final bill.

## 🚀 Features

- Customer name input and personalized welcome message.
- Menu containing 12 food and beverage items.
- Menu selection using item numbers.
- Multiple item ordering in a single session.
- Quantity selection for each item.
- Automatic individual price calculation.
- Grand total calculation.
- Option to finish ordering by typing `no`.

## 🛠️ Technologies Used

- Python 3
- Dictionaries
- Lists and loops
- Conditional statements
- User input handling
- Basic arithmetic operations

## ⚙️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/shlok-AI-cpu/Basic-Menu
   ```

2. Open the project folder:

   ```bash
   cd basic-menu
   ```

3. Run the Python file:

   ```bash
   python main.py
   ```
